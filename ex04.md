# Deadlock entre asyncio e OpenMP

O Deadlock ocorre quando a tarefa asyncio e OpenMP dependem um do outro mutuamente e ficam se bloqueando.

Exemplo:

Uma coroutine asyncio faz um await esperando o fim de uma região paralela OpenMP.

Ao mesmo tempo, uma thread OpenMP tenta enviar resultado de volta ao event loop via callback ou future

O event loop esá parado no await, não processa novos callbacks/futures. A thread OpenMP conclui o trabalho, tenta notificar ao loop mas o loop está parado e não recebe a notificação e não processa.
